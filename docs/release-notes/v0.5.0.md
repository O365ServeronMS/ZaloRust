## Zalo v0.5.0

- Đổi tên sản phẩm hiển thị từ "ZaloRs" thành **Zalo** trong toàn bộ giao diện, cửa sổ, thông báo và cài đặt.
- Thư mục cài đặt mặc định trên Windows: `%LOCALAPPDATA%\zalo-web` (cùng khoá đăng ký gỡ cài đặt `zalo-web`, tránh trùng với app Zalo chính thức).
- Repo GitHub đổi tên thành `ZaloRust`; trình cập nhật trỏ về repo mới.
- Không đổi: định danh `com.o365serveronms.zalors`, scheme `zalors://`, dữ liệu tài khoản hiện có.
