## Zalo v2026.11.10

Phiên bản đầu tiên theo CalVer `YYYY.M.D` (không có số 0 đứng đầu), chỉ phát hành bộ cài Windows NSIS.

- Thương hiệu và mọi thông báo dùng tên **Zalo**; repo là `ZaloRust`; thư mục cài mặc định `%LOCALAPPDATA%\zalo-web`.
- Giao diện tiếng Việt (mặc định) và English; sao lưu/khôi phục cục bộ có mã hoá (Cài đặt → Sao lưu) kèm biểu tượng mới.
- Tauri 2.12.5; Node 26 trong CI; các GitHub Actions được ghim SHA bản mới.
- Trình cập nhật: khi repo riêng tư (HTTP 401/403/404) báo rõ "không truy cập được các bản phát hành" thay vì "lỗi mạng".
- Bộ cài chỉ còn NSIS (bỏ MSI/DEB/AppImage/DMG); workflow `windows-build` tự tạo GitHub Release khi đẩy tag `v*`.
- Ô mật khẩu sao lưu được xoá sau khi xuất.
